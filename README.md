# 🎈 Μικροί Μαθητές (Mikroi Mathites)

> Διαδραστική εκπαιδευτική εφαρμογή (PWA) για παιδιά προσχολικής και πρώτης σχολικής ηλικίας (2–8 ετών).

Μια σύγχρονη, πολύχρωμη και ασφαλής εφαρμογή σχεδιασμένη για **iPad, iPhone, Android tablets/smartphones, Mac και PC**, με πλήρη υποστήριξη οθόνης αφής, offline λειτουργία και ελληνική γλώσσα.

---

## ✨ Κύριες Εκπαιδευτικές Ενότητες

1. **🔤 Ελληνική Αλφαβήτα (Α–Ω):** Φωνητική εκμάθηση και διαδραστική σχεδίαση γραμμάτων με έξυπνο έλεγχο ακρίβειας (anti-scribble) και φωνητική σύνδεση («όπως αρκούδα», «όπως βάτραχος»).
2. **🔢 Αριθμοί (1–25):** Διαδραστική καταμέτρηση αντικειμένων ένα-προς-ένα με επιβράβευση και ελληνική προφορά.
3. **➕ Διασκεδαστικά Μαθηματικά:** Πρόσθεση, Αφαίρεση, Πολλαπλασιασμός και Διαίρεση με οπτική αναπαράσταση αντικειμένων (κουτάκια ομάδων, ισόποσο μοίρασμα).
4. **🐾 Ζωάκια & Πραγματικοί Ήχοι:** Αυθεντικές ηχογραφήσεις ζώων (σκύλος, γάτα, βάτραχος, πρόβατο, πάπια, αγελάδα, λιοντάρι, κόκορας) και παιχνίδι κουίζ ήχων.
5. **🎹 Παιδικό Πιάνο:** 8χρωμο πιάνο με νότες και διαδραστικά τραγούδια («Ωδή στη Χαρά» του Μπετόβεν, «Φεγγαράκι μου λαμπρό»).
6. **🎈 Σπάσε τα Μπαλόνια:** Παιχνίδι αντανακλαστικών και συντονισμού κινήσεων.
7. **🧩 Ταίριαξε τις Σκιές:** Ανάπτυξη οπτικής αντίληψης με αναγνώριση σιλουετών.
8. **🎨 Χρώματα & Σχήματα:** Γνωριμία με τα βασικά γεωμετρικά σχήματα και χρώματα.
9. **🧠 Παιχνίδι Μνήμης:** Κλασικό παιχνίδι αντιστοίχισης καρτών.
10. **📖 Άλμπουμ Αυτοκόλλητων:** Δημιουργικό κόλλημα αυτοκόλλητων σε 3 σκηνικά (Βυθός, Φάρμα, Διάστημα).
11. **✍️ Μαγικός Πίνακας:** Ελεύθερη ζωγραφική με μαγικά πινέλα και δυνατότητα αποθήκευσης της εικόνας.

---

## 🛡️ Σύστημα Προφίλ & Ασφάλεια Γονέα

* **Προφίλ Παιδιών:** Δημιουργία πολλαπλών παιδικών προφίλ με προσωπικά avatars και συλλογή αστεριών.
* **Ζώνη Γονέων (Parent Gate):** Ασφαλές αριθμητικό κλείδωμα για προστασία των ρυθμίσεων.
* **Βάθρο Πρωταθλητών:** Εβδομαδιαίος πίνακας επιτευγμάτων που ανανεώνεται κάθε Δευτέρα.
* **Μαγικό Κατάστημα:** Εξαργύρωση αστεριών για νέα avatars και ειδικά πινέλα.

---

## 🛠️ Τεχνολογίες

* **Frontend:** React 18, Vite
* **Styling:** Tailwind CSS, Safe-Area insets (για notch & home indicators σε iOS/Android)
* **Ήχος:** Web Audio API (Synthesizers & Authentic MP3s)
* **Γραφικά:** HTML5 Canvas (High-DPI / Retina calibration, Unified Pointer Events)
* **Icons:** Lucide React
* **Εφέ:** Canvas-Confetti

---

## 🚀 Τοπική Εκτέλεση (Local Development)

```bash
# Εγκατάσταση εξαρτήσεων
npm install

# Εκκίνηση development server
npm run dev

# Παραγωγή production build
npm run build
```

---

## 📱 Εγκατάσταση ως Εφαρμογή (PWA)

* **Σε iPhone / iPad:** Ανοίξτε το Safari, πατήστε το κουμπί **Κοινοποίηση** (Share) και επιλέξτε **«Προσθήκη στην οθόνη αφετηρίας»** (Add to Home Screen).
* **Σε Android:** Ανοίξτε το Chrome, πατήστε το μενού (τρεις τελείες) και επιλέξτε **«Εγκατάσταση εφαρμογής»**.
